# Per-object Multi-crop 与逐轨迹选项概率报告

日期：2026-08-24

## 改动

裁剪规则已从“把多个目标合成一个 union Crop”改为“每个对象独立裁剪并放大”：

- Analyzer 可以返回 1–3 个对象查询；
- Grounding DINO 对每个查询分别选框；
- 每个框单独扩展上下文并保存为一张图片；
- Teacher 前缀按对象顺序插入全部 Crop；
- blank、random、shuffled 对照匹配 Crop 数量和尺寸。

这解决了分散对象被一个大矩形包住、背景占比过高的问题。以 index 116 为例，旧 union Crop 占原图 48.4%；改后得到三张独立 Crop，面积分别为 0.3%、0.3% 和 14.3%。不过，前两张实际都落在同一辆警用面包车上，说明 Grounding DINO 没有把“小红车”查询独立定位出来。这属于查询定位错误，而不是裁剪合并错误。

## 逐 rollout 条件化概率探针

旧的 prompt-level 选项概率每题只有一个值，不能区分同组 8 条 rollout。新的探针保留每条 rollout 的解释，移除其末尾答案，然后在相同解释之后计算 A/B/C/D 的归一化下一步概率。因此可以分别统计 20 条正确轨迹和 20 条错误轨迹。

### 正确轨迹（20 条）

| 条件 | 正确选项概率 | 相对 plain | argmax 仍为正确选项 |
|---|---:|---:|---:|
| plain | 0.8050 | — | 100% |
| text + multi-crop | 0.7943 | -0.0107 | 100% |
| crop only | 0.7951 | -0.0099 | 100% |
| blank | 0.8003 | -0.0047 | 100% |
| random | 0.7925 | -0.0124 | 100% |
| shuffled | 0.7906 | -0.0143 | 100% |

完整前缀使已经正确的轨迹平均置信度轻微下降，但没有改变任何正确 argmax。text-only 降幅更大（-0.0364），说明图片部分抵消了泛化语言提示的扰动。

### 错误轨迹（20 条）

| 条件 | 正确选项概率变化 | 原错误选项概率变化 | 正确-vs-错误 margin 变化 | 两者同时朝理想方向 |
|---|---:|---:|---:|---:|
| text + multi-crop | **+0.0128** | **-0.0153** | **+0.0280** | **70%** |
| crop only | +0.0081 | -0.0100 | +0.0181 | 65% |
| text only | +0.0066 | -0.0058 | +0.0124 | 65% |
| blank | -0.0007 | +0.0025 | -0.0032 | 65% |
| random | -0.0027 | +0.0055 | -0.0082 | 60% |
| shuffled | -0.0045 | +0.0050 | -0.0095 | 65% |

错误轨迹中，plain 的平均正确选项概率为 0.1202，完整前缀后为 0.1330；原错误选项概率从 0.8748 降至 0.8595。80% 的错误轨迹上，原错误选项概率有所下降。与 blank/random/shuffled 的反方向变化相比，这个信号具有视觉内容特异性。

但它仍是弱的校正信号：错误轨迹的正确选项 argmax 比例在前后都为 15%，没有一条从错误 argmax 真正翻转为正确。当前结果支持“可作为 OPD 的软监督候选”，尚不足以证明单次前缀干预能够纠正答案。

## 逐题现象

- index 140：错误轨迹上的正确选项概率 +0.0489、错误选项 -0.0489，校正信号最强；但正确轨迹置信度 -0.0572。
- index 56：错误轨迹正确选项 +0.0059、错误选项 -0.0160；per-object Crop 比旧 union 明显更合理。
- index 116：错误轨迹正确选项 +0.0147、错误选项 -0.0147；尽管有一个查询误定位，整体仍为正。
- index 154：错误轨迹正确选项 +0.0128、错误选项 -0.0128，且正确轨迹也 +0.0128。
- index 189：错误轨迹正确选项 -0.0159、错误选项 +0.0159，是明确反例；同区域重复 Crop 值得重点排查。
